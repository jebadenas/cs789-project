How to code (read this first)
  1. Read the whole highlighted passage, then the text around it. You are judging what the tutor saw: the passage in its context.
  2. Ask one question: why would a sensible reader say this shows no current problem? Pick the one code that answers it best. If two fit, take the one higher in the list.
  3. Code what is written, not what you know about the team. Don't use anything outside the page.
  4. Then say who you side with. "Tutor" if you also see no problem, "Tool" if the flag was fair and the tutor was strict, "Unsure" otherwise. This is separate from the code.
  5. Write a note whenever you hesitate or choose "Other". One line is enough. Notes are where new codes come from.
  6. Don't change the codes halfway through. If a new reason keeps coming up, note it and keep going; we decide afterwards whether it becomes a code.
  7. When all are coded, take a break, then do the re-check. The app shows 10 snippets again without your earlier answer. Comparing the two tells us how stable your coding is.
